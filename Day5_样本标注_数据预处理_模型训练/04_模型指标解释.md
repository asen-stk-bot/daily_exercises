## 一、训练时打印的列（train batch 输出）

`yolo segment train ...` 每完成一个 epoch（更细粒度是每 N 个 batch），会输出一行：

```
Epoch  GPU_mem  box_loss  seg_loss  cls_loss  dfl_loss  Instances  Size
```

逐列解释：

| 列 | 含义 | 越低越好 | 备注 |
| --- | --- | --- | --- |
| `GPU_mem` | 当前占用的显存（GB） | — | CPU 训练时为 0 或空 |
| `box_loss` | **回归框**的损失：预测框 vs 真值框的差距 | ✅ | detect 任务核心损失之一 |
| `seg_loss` | **分割 mask** 的损失：像素级 BCE（实例分割才有） | ✅ | 皮带边缘的指标 |
| `cls_loss` | **分类**的损失：预测类别 vs 真值类别的交叉熵 | ✅ | 类别越多越难压 |
| `dfl_loss` | Distribution Focal Loss（边界分布损失） | ✅ | YOLOv8 引入，框边界的精细回归 |
| `Instances` | 本 batch 平均目标数 | — | 数据集决定 |
| `Size` | 输入图片边长 | — | 训练时一般 640 |

`yolo detect train` 没有 `seg_loss`，其他列一致。

### 如何看 loss 曲线

打开 `runs/<task>/train/results.png`，会有 4~6 张子图：

1. **train/box_loss** + **val/box_loss** —— 都应该向下走，val 不反弹
2. **train/seg_loss** + **val/seg_loss** —— 同上（detect 任务无此图）
3. **train/cls_loss** + **val/cls_loss** —— 同上
4. **train/dfl_loss** + **val/dfl_loss** —— 同上
5. **metrics/precision(B)** + **metrics/recall(B)** —— 应该向 1 走
6. **metrics/mAP50(B)** + **metrics/mAP50-95(B)** —— 衡量综合精度

**健康训练的样子**：所有 loss 下降、val 曲线不显著高于 train（差距 < 0.1 算正常）。

## 二、验证（val）时打印的指标

`yolo val model=best.pt data=data.yaml` 输出示例：

```
Class     Images  Instances      P        R   mAP50  mAP50-95
all        200        412     0.876   0.812   0.852     0.624
belt      200        412     0.876   0.812   0.852     0.624
```

逐列解释：

### 1. P（Precision，查准率 / 精度）

$$ P = \frac{TP}{TP + FP} $$

> 含义：模型说「这是皮带」时，**说对的占多少比例**。
> 越接近 1，**误报越少**。

PPT 里的 YOLO 损失函数分解（slide 8）三部分之一就是 P。

### 2. R（Recall，查全率 / 召回率）

$$ R = \frac{TP}{TP + FN} $$

> 含义：所有「真正的皮带」里，**模型找回了多少**。
> 越接近 1，**漏检越少**。

### 3. P vs R 的权衡（重要）

- P 高、R 低 → 模型**挑剔**：宁可不报也不报错 → 漏检多
- P 低、R 高 → 模型**激进**：所有可疑的都说成皮带 → 误报多
- 训练后期通过 **置信度阈值** 调权衡

### 4. mAP50（mean Average Precision @ IoU=0.5）

$$ AP_{50} = \int_0^1 P(R) \, dR \quad \text{（单类 PR 曲线下面积）} $$
$$ mAP_{50} = \frac{1}{N} \sum_{i=1}^{N} AP_{50}^{(i)} \quad \text{（多类平均）} $$

> 含义：把 IoU 阈值固定为 **0.5**（预测框与真值框重合 50% 以上算对），所有类别 AP 的均值。
> 越接近 1 越好，**最常用的总体指标**。

### 5. mAP50-95（严格指标，COCO 标准）

$$ mAP_{50:95} = \text{mean of } mAP_{IoU} \text{ for } IoU \in \{0.5, 0.55, 0.6, ..., 0.95\} $$

> 含义：把 IoU 从 0.5 到 0.95 每 0.05 取一个 mAP 再求平均。
> **对位置/大小要求更严**，更能反映真实可用性。
> YOLO 默认报告它。

### 6. 类别一行 vs all

- `all` 是所有类别的平均
- 每个类别一行 → 看哪一类偏弱
- 类别偏弱通常因为：样本数少、bbox 大小差异大、遮挡严重

## 三、其他常见指标

### 1. IoU（Intersection over Union，交并比）

$$ IoU = \frac{|A \cap B|}{|A \cup B|} $$

> 含义：预测框 A 与真值框 B 的**重合度**。
> 0 = 完全不交，1 = 完全重合。
> YOLO 默认 `IoU > 0.5` 算 TP，`0.5~0.95` 算 mAP50-95。

### 2. Dice 系数（分割任务，等价于 F1）

$$ Dice = \frac{2 |P \cap G|}{|P| + |G|} $$

> 含义：预测 mask 与真值 mask 的**像素重合度**，0~1。
> 与 IoU 是同一族指标，**Dice ≥ IoU**，当 mask 较小时差异更大。
> 实例分割里 mAP50-95 的 mask 通道（`mAP50-95(M)`）即基于 mask IoU 计算。

### 3. F1 / F2 分数

$$ F_\beta = (1 + \beta^2) \cdot \frac{P \cdot R}{\beta^2 P + R} $$

> F1 = P 和 R 的调和均值（β=1）；F2 更看重 R（β=2）。
> 一般用 F1 看综合性能。

### 4. Confusion Matrix（混淆矩阵）

`runs/<task>/train/confusion_matrix.png` 和 `confusion_matrix_normalized.png`：

- 对角线 → 正确分类
- 非对角线 → 哪两个类被搞混了

> 实战意义：如果 `belt ↔ crack` 混淆高，说明模型分不清皮带的完好和破损——多半是**特征重叠**，需要：
> 1. 重新审视标签是否一致
> 2. 增加这两类的训练样本
> 3. 用更细粒度的类别名

### 5. PR Curve

`runs/<task>/train/PR_curve.png`：

- 横轴 R，纵轴 P，曲线下面积 = AP
- 越靠近右上 → 越好

## 四、训练中常见的「坏症状」与解读

| 现象 | 解读 | 怎么办 |
| --- | --- | --- |
| `box_loss` 一直高（> 2.0）不下降 | bbox 标注错 / imgsz 不够 | 抽样检查标签；用 imgsz=1280 重训 |
| `cls_loss` 高 / 准确率不上去 | 类别混淆 / 样本不均 | 看 confusion matrix；对少类做 `oversample` 或增广 |
| `seg_loss` 下降但 mask 看着不准 | 标注多边形顶点错位 | 抽样把真值 mask 可视化对比 |
| train loss ↓ val loss ↑（**过拟合**） | 模型背下了 train | 加数据增强 `mosaic=1.0 mixup=0.1`；早停；`close_mosaic=10` |
| val mAP50 高 mAP50-95 低 | 框位置不精准 | 增 imgsz 到 1280；或换 `yolo11m.pt` 更大模型 |
| P 高 R 低 | 阈值太严 | 调低 `conf`（如 0.15） |
| P 低 R 高 | 阈值太松 | 调高 `conf`（如 0.5） |
| P R 都低 | 模型欠拟合或数据/标签有严重问题 | 先用 imgsz=320 + epochs=1 跑通，再排查 |

## 五、Ultralytics `model.val()` 返回的字段

Python 调用：

```python
from ultralytics import YOLO
model = YOLO("runs/segment/train/weights/best.pt")
metrics = model.val(data="data.yaml")
# metrics.box   → 目标检测指标（detect / segment 都有）
# metrics.seg   → 分割 mask 指标（仅 segment）
# metrics.names → 类别名 dict
```

常用：

```python
print(metrics.box.map)      # mAP50-95
print(metrics.box.map50)    # mAP50
print(metrics.box.map75)    # mAP75
print(metrics.box.mp)       # mean Precision
print(metrics.box.mr)       # mean Recall
print(metrics.seg.map)      # mAP50-95 (mask)
print(metrics.seg.map50)    # mAP50 (mask)
```

## 六、给老师的「一句话总结」

> 训练过程中，YOLO 用 `box_loss + cls_loss + (seg_loss) + dfl_loss` 四个损失做反向传播；
> 训练结束后用 `mAP50` 看整体精度，用 `mAP50-95` 看精细度，用 `P/R` 调阈值；
> 类别偏弱看 `confusion_matrix` 定位混淆，框不准看 `results.png` 里 val 曲线的反弹情况。
> 皮带边缘属于实例分割，重点看 `seg_loss` 和 `mAP50(M)` 这两条曲线。
