### 3. CPU / GPU 选型

- 有 NVIDIA 显卡：训练前确保已装 GPU 版 PyTorch（`torch.cuda.is_available()` 返回 True），`device=0` 指定 GPU
- 无显卡：使用 CPU（`device=cpu`），速度慢几十倍，作业跑得动但慢

## 二、训练命令（PPT slide 20）

### 皮带 — 实例分割

```bash
cd D:\皮带监控\belt_seg_split

# PPT slide 20 原始命令
yolo segment train model=yolo11n-seg.pt data=data.yaml epochs=100 imgsz=320

# 实际推荐（CPU 上 imgsz=320 速度可控）
yolo segment train model=yolo11n-seg.pt data=data.yaml epochs=100 imgsz=640 device=cpu batch=8
```

### 安全帽 / 工程车 / 烟火 / 异物 — 目标检测

```bash
cd D:\烟火\smoke_fire_split1

# PPT slide 20 原始命令
yolo detect train model=yolo11n.pt data=data.yaml epochs=100 imgsz=320

# 实际推荐
yolo detect train model=yolo11n.pt data=data.yaml epochs=100 imgsz=640 device=cpu batch=16
```

### 关键参数说明

| 参数 | 含义 | 推荐 |
| --- | --- | --- |
| `model` | 预训练权重 | `yolo11n.pt`（小）/ `yolo11s.pt`（中）/ `yolo11m.pt`（大） |
| `data` | 数据集 yaml | `data.yaml` |
| `epochs` | 训练轮数 | 100 是常见默认值，过拟合时减半 |
| `imgsz` | 输入方形边长 | 训练时一般 640，CPU 可降到 320 |
| `batch` | 批大小 | GPU 显存吃紧就调小；CPU 用默认即可 |
| `device` | `0` / `0,1` / `cpu` | 默认会自动选 |
| `project` | 输出根目录 | 默认 `runs/` |
| `name` | 本次训练子目录 | 默认 `train` |

## 四、训练意外终止？续训（PPT slide 22）

```bash
# 续训（必须到 split 的目录下）
yolo train resume model=./runs/detect/train4/weights/last.pt
```

注意事项（PPT slide 22）：

- **关闭所有其他进程**，让出更多空闲内存
- **C 盘和 D 盘空闲空间都建议 > 30 GB**（训练过程中 YOLO 会缓存数据 / 写日志 / 复制权重）
- 如果上次用了 `device=cpu`，续训时也要保持 `device=cpu`（自动从 last.pt 恢复）

## 五、训练后做验证 / 推理

### 验证（看模型在 val 上的指标）

```bash
yolo val model=runs/segment/train/weights/best.pt data=data.yaml
# 输出: mAP50, mAP50-95, precision, recall 等
```

### 推理（拿新图片看效果）

```bash
yolo segment predict model=runs/segment/train/weights/best.pt source=新图片/ save=True
```

或者直接调 Python：

```python
from ultralytics import YOLO
model = YOLO("runs/segment/train/weights/best.pt")
results = model.predict(source="新图片/", save=True, conf=0.25)
```

## 六、训练中的常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `train: Scanning ... labels... 0 < 1` | train 集空 / 路径错 | 检查 `data.yaml` 中 `train: train/images` 是否相对 `path` 写对 |
| `No labels found` | labels 目录空 / 文件后缀不对 | 标签必须和图片同名，扩展名 `.txt` |
| `CUDA out of memory` | batch 太大 | `batch=8` 或 `batch=4` |
| 训练几十个 epoch 后 loss 不再下降 | 过拟合 | 早停 / 减小 epochs / 加数据增强（`mosaic=1.0 mixup=0.1`） |
| 训练时 Windows worker 死锁 | 多进程 DataLoader 在 Win 上不稳 | `yolo ... workers=0` |
| 训练中断 | 内存/磁盘满、机器休眠 | 用 `yolo train resume model=last.pt` 续训 |
| `mAP50` 高但 `mAP50-95` 低 | 框位置/大小不太准 | 增大 `imgsz`，或多训几轮 |
